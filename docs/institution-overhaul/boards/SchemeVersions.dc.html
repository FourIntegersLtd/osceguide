Steps
  1. Each tab on this board is one screen or state. Build every one; none is optional.
  2. Each button that opens a box is a Modal (or ConfirmModal for a yes/no). Open each box on this board to see its words.
  3. Copy every word on the board exactly, including the empty, error and busy texts. Put nouns through useAssessWords so hire reads its own words.
  4. Find the button's call in the list above, by its summary. Today's caller (the "Now:" file) already makes that call: reuse its function from that file's api.ts. Do not write a new fetch.
  5. Show a write button only to the person in "Who sees it". Anyone else gets the same screen with no write buttons.
  6. Write a failing test first (Testing Library, assert the literal words), then build, then run npm run ci.
  7. Live data comes from the existing SSE streams (useMeEvents or the */stream route above). Never poll.
  8. Nothing that exists today may disappear. If a control on today's screen is not on this board, stop and ask.

Archive this version?
