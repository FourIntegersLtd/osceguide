# Owners: which agent owns which path

Every tracked source file under `api/`, `web/` and `assessment/` has exactly
one owner. `api/tests/guards/test_ownership.py` fails if a file matches no row
or two rows, so a new folder forces a decision here.

- **Source** means `*.py`, `*.ts`, `*.tsx`, `*.mjs`, `*.js`, `*.sql`, `*.sh`.
  Not source: `node_modules`, `__pycache__`, `web/src/foundation/platform-client/schema.d.ts`
  (generated), `openapi.json`, assets, docs and config.
- **Row format:** `` `glob`, `glob`, `!excluded` | owner ``. `*` stays in one
  folder, `**` crosses folders, `{a,b}` expands, `!glob` removes files from the row.
- **A test follows its subject.** Shared test infrastructure, guards and
  migrations belong to `staff-console-owner`.
- Where two areas touch one file, the owner is the one whose rule file names it
  (`.claude/rules/`). Voice starts rooms, marking computes scores, institution
  runs the workflow.
- Retired and frozen code outside these three folders (`livekit/`, the old
  backends) is nobody's: do not edit it.
